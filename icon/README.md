# Retro — Abstract Dossier Mark

Not a letter, not a card — just a ledger star.

**Inspired by Claude's soft asterisk**, but dossier-born:
- **4 petals = 4 sections** (Chat / Notes / DEN / Flashcards) as rounded bars (`16×18`, `rx 8`)
- **Paper gaps** cut out — like ledger lines, negative space is part of the mark
- **Indigo core dot** `#6366f1` — the memory, the one accent that holds it together
- **Ink `#141413` on Paper `#fafafa`**, `rx 22` bg, `rx 9` center — same tokens as the app

Scales: 16px favicon (just the 4 bars + dot), 32px app, 512px store. No letter, no card — purely abstract, like Claude. Works in one color (just Ink) for stamps.

View at `http://localhost:8000/icon.svg` — `icon/icon.svg` is the master.
